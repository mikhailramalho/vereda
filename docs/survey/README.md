# Survey

Dated measurements and design decisions, including the ones not adopted, one
file per entry: `YYYY-MM-DD-short-title.md`, starting with a `#` title and a
"Recorded YYYY-MM-DD." line. Add a new file for each new entry rather than
editing a shared one, so that pull requests never conflict over this
directory; the file names sort by date, so there is no index to keep.

The entries up to 2026-11-23 were one file, `docs/spike-survey.md`, until it
was split here; `2026-11-21-milestone-0-survey.md` is that file's opening, the
survey of milestone 0's candidate tasks.
